# CSV売上自動集計ツール

CSVに記録された商品名・数量・単価から、商品別の販売数量と売上額を自動集計するPythonツールです。

## 機能

- `sales.csv` を読み込む
- 同じ商品をまとめて数量と売上を集計する
- 商品別の結果と合計売上をターミナルに表示する
- 集計結果を `result.csv` に出力する

## 使用技術

Python 3、標準ライブラリ `csv`、`collections.defaultdict`。追加ライブラリのインストールは不要です。

## 実行方法

このフォルダで実行します。

```bash
python3 main.py
```

実行結果：

```text
りんご: 5個、750円
バナナ: 5個、500円
合計売上: 1250 円
result.csvを作成しました
```

## ファイル構成

- `main.py`：売上自動集計プログラム
- `sales.csv`：入力サンプル
- `result.csv`：集計結果サンプル（実行時に上書き）
- `README.md`：使い方
